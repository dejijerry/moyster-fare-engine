# moyster-fare-engine
Development of metro payment system based on a prepaid NFC-enabled card, called MoysterCard, which commuters will tap at the entry and exit points of metro stations. Fare calculations for commuters is divided into 2 zones and determined by peak/off peak time and fare cap rules

The **fareCalculator.ts** is a self contained code snippets for the calculation of the fares. The code and the sample journey data are included in the file. This can be run on any terminal and the output is provided on the terminal




The other files contains a more robust system with unit testing:

In your terminal:

run npm install to install all the required dependencies 
then run npm start
